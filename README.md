## 风格基准

严格对齐 [oldmacdonald.xyz](https://oldmacdonald.xyz)：
- 背景：纯白 `#FFFFFF`
- 正文：`#1a1a1a`
- 元数据：`#888888`
- 字体：思源宋体（中文）+ Charter/Iowan Old Style（英文）
- 最大宽度：~720px
- 无装饰、无 emoji、无渐变、无阴影、无卡片 UI

## 写作原则

- **不写**赞美式语言（"伟大的"、"传奇的"）
- 失败必须诚实写
- 承认不确定（标"待考证"）
- 站主解读用第一人称，与客观资料明确区分
- 标签标注置信度（高/中/低）+ 来源
