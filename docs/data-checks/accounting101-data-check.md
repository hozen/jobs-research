## 三、无法核验项

- IFRS 全球采用地图（Session 1 幻灯 10）：交互图截图，只能反映课件制作当时的采用状态，
  无法据此核验今天的采用情况。
- 课后题数据表（Session 2A / 3A / 4A / 6A）：均为课件截图，数字与图一致即认为无误；
  未与各公司原始年报逐项对表（课件本身即取自各公司公开报表截图）。
- 各公司财报数字本身是**课件引用**的结果，本次核验只保证「译文数字 = 课件图上数字」，
  不保证课件引用与公司最新披露完全同步（课件年份为 2019–2020）。
